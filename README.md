# 😊 Emotion Text Classification using Deep Learning

## 📌 Project Overview

An end-to-end NLP project that classifies text into six emotions using deep learning. The project compares multiple deep learning algorithms and deploys the best-performing BiGRU model as an interactive web application.

## 🎯 Objective

- Build an accurate text emotion classification model.
- Compare multiple deep learning architectures.
- Develop and deploy a real-time NLP inference pipeline.

## 📊 Dataset Description

- **Dataset:** dair-ai/emotion
- **Source:** Hugging Face Datasets
- **Size:** 16,000 text samples
- **Classes:** Sadness, Joy, Love, Anger, Fear, and Surprise
- **Preprocessing:** Tokenization, text sequence preparation, and class-weight computation.

## 🛠️ Tech Stack

- **Languages:** Python, HTML, CSS, JavaScript
- **Deep Learning:** TensorFlow, Keras, BiGRU, RNN, LSTM
- **NLP:** Hugging Face Datasets, Tokenizer
- **Backend:** FastAPI
- **Deployment:** Render
- **Development:** Jupyter Notebook

## 🚀 Results & Deployment

- Compared deep learning algorithms like RNN, LSTM, GRU and BiGRU to identify the best-performing architecture.
- Achieved **92% validation accuracy** using the BiGRU model.
- Saved the trained model and tokenizer for inference.
- Built a FastAPI backend for real-time predictions.
- Developed an interactive web interface for emotion classification.
- Deployed the application on Render.
